# Planning Development Log

## Purpose
Define and approve the gym workout tracker before implementing features. Selected prompt excerpts are retained as evidence; this is not a complete conversation transcript.

## 1. Feature order
**Prompt excerpt:** “can you keep the features in order from the assingment and then add the three required one th end?”

**Decision:** Keep the seven required features in the assignment’s order, followed by reusable workout templates, per-set rep logging, and repeating a session.

**Revision:** Reordered the proposed feature list to match the assignment.

## 2. Editable workouts and preserved history
**Prompt excerpt:** “There should be a way to track those changes and not lose data for an exercises that was previously included but now isn't”

**Decision:** Editing a saved workout creates a dated version. Removing an exercise from the current template preserves previous versions and all previously logged sets, weights, reps, and progress data.

**Revision:** Expanded the template feature and revised the database plan to nine tables.

## 3. Feature titles
**Prompt excerpt:** “I also want to remove "extra #" from step titles”

**Decision:** Remove the extra-number labels while preserving feature numbering and order.

## Status
The plan was reviewed and approved before feature implementation. Preserve the original plan and record actual outcomes later in Plan vs. Reality. Future feature logs will retain relevant prompts, response excerpts, checks, and corrections for reflection evidence.
