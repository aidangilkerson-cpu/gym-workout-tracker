---
name: Between-set workout logging
description: The intended mobile workflow requires an in-progress workout to survive phone locking between sets.
---
Users need to log results between sets, locking their phone while performing a set and reopening the same workout afterward—not enter an entire workout only after finishing.

**Why:** The student identified lost unsaved entries after phone lock/account retry as the stranger test's biggest problem because it prevents using the app as intended.

**How to apply:** Treat draft continuity across mobile background/resume and transient account verification as essential. Preserve authentication and account isolation; never solve continuity by exposing a draft before identity is confirmed or silently saving unfinished training as completed.
