---
name: Exercise note scope
description: User-selected scope for carrying previous exercise notes into later workouts.
---

An editable note for an exercise should carry across all of that user's workouts, rather than remain specific to one workout preset.

**Why:** When asked whether notes should stay within the same workout or carry across different workouts, the user selected “Across all my workouts.”

**How to apply:** Use this scope when defining and implementing previous exercise notes. Do not narrow note lookup to the selected preset without discussing that change with the user. This records the requested behavior, not a claim that it has been built.
